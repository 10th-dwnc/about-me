# about-me

바이브코딩 동아리 GitHub 협업 실습 저장소입니다.

## 제출 방법
1. 이 저장소를 Fork
2. 내 Fork를 clone → `work` 브랜치 생성
3. `내아이디.html` 파일로 자기소개 페이지 작성 (바닐라 HTML/CSS)
4. commit → 내 Fork로 push
5. PR 생성 — **base 브랜치를 본인 GitHub ID 브랜치로 변경** (기본값 main 아님!)

## 규칙
- 파일명은 반드시 본인 GitHub ID
- 다른 사람 파일은 수정하지 않기
- API 키 등 비밀 값은 절대 커밋하지 않기
